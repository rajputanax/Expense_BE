============================= Express Validator ========================================
 install package command   [ npm install express-validator ] ===========================

is a library used with Express.js to validate user input coming from HTTP requests. It simplifies the validation process by providing methods like
body() and validationResult().
this middleware provide you some builtin method to validate user data by giving us (validationResult) method along with body() and some methods to check the body data 
you can create a custom middleware and then join your custom middleware with validationResult got everything from users request and compare it  through express_validator
